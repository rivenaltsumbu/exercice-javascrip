# Exercice JavaScript : Ma liste de tâches

## Objectif
Construire une petite application pour pratiquer :
- `querySelector()`
- les événements (`submit`, `click`)
- les tableaux et `forEach()`
- la création d'éléments HTML (`createElement`)
- les conditions et les fonctions
- (bonus) `localStorage`

## Ouvrir dans VS Code
1. Télécharge et décompresse `exercice-javascript.zip`.
2. Dans VS Code, clique sur **Fichier > Ouvrir un dossier**.
3. Choisis le dossier `exercice-javascript`.
4. Ouvre `script.js` et complète les lignes `TODO`.
5. Ouvre `index.html` dans ton navigateur. Tu peux aussi utiliser l'extension **Live Server** de VS Code.

## Règles de l'exercice
1. Saisir une tâche puis cliquer sur **Ajouter**.
2. Refuser les champs vides.
3. Afficher toutes les tâches dans la liste.
4. Pouvoir marquer une tâche comme terminée.
5. Pouvoir supprimer une tâche.
6. Mettre à jour le compteur.

## Conseils
Commence par faire fonctionner l'ajout. Ensuite, fais l'affichage, puis la suppression et le bouton « Terminer ». Ne regarde pas de solution toute faite : essaie d'abord.

Bon codage !
